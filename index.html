About This Dashboard

This is an independent monitoring dashboard tracking the 2026 Bhotekoshi/Rasuwa flash flood event. It is not an official government source. For authoritative figures, refer to the Nepal Disaster Risk Reduction Portal and the National Disaster Risk Reduction and Management Authority (NDRRMA).

Update Cadence

Data auto-refreshes every 45 seconds from the JSON snapshot. The snapshot itself is updated by a scheduled Node.js script pulling from public APIs (ReliefWeb, GDACS, Wikipedia). See the README for scheduling instructions.

Data Integrity

Every figure carries source attribution. Where sources disagree, a range is shown. Stale data is flagged prominently. Figures may be revised as verification continues.
