# Nepal Flood Live Monitor

A mobile-first Nepal flood monitoring dashboard based on the supplied
visual reference.

## Features

- Dark emergency dashboard
- Flash flood warning
- Live status indicator
- Deaths statistic
- Missing persons statistic
- Rescued persons statistic
- Affected population statistic
- Affected districts map
- Recent flood updates
- Relief effort statistics
- Safety information
- Mobile bottom navigation
- Responsive layout
- JSON-based dashboard data
- Automatic data refresh every 45 seconds
